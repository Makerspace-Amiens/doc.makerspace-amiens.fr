Welcome to the **Project Methodology** workshop!

You will learn to scope, document and manage a project from start to finish: creating and maintaining a GitHub repo, organising teamwork, documenting as you go rather than at the last minute, and presenting each building block of your project properly (electronics, mechanics, software).

## What you will learn

- Scoping a project: need, specification, life cycle
- Documenting continuously, not only at the end
- Organising a team and communicating effectively
- Using Git and GitHub to version, track and review the work
- Building and maintaining a Jekyll documentation site
- Documenting each building block of the project (electronics, mechanics, code, tests, assembly)
- Closing and handing over a project properly

## Why this project?

A successful project is not just a prototype that works: it must be something others can understand, pick up and hand on. This workshop gives the method and the tools used at the MakerSpace so that each student project remains usable after submission: for you, for the next team, and for the school.
