The whole project is carried out in **Onshape**, a powerful tool you have already used before. Very similar to software such as SolidWorks or Fusion 360, Onshape stands out for its **accessibility** and its **collaborative** nature. Available directly in a browser, it runs on any PC configuration, so everyone can work in *real time* on the **same file shared online**.

For this project, we provide **a starter file** containing the assembly and all the parts of the **Otto-MKS**. After **copying** it, you will first print it, assemble it and program it, then **modify** it to make **your own version**!

Make sure you follow the steps below carefully to get your project off to a good start.
