{%- comment -%} Graphique Chart.js. Mêmes paramètres que l'include du template étudiant (template-project/docs/_includes/graphique.html), plus la saisie directe des données. Depuis un CSV : {% include graphique.html csv="mesures.csv" titre="Décharge de la batterie" y="Tension (V)" %} csv : chemin relatif à la page (fichier dans le sous-dossier du même nom que le .md), ou absolu s'il commence par « / ». Le CSV : une ligne d'en-tête, la 1re colonne pour l'axe X, une colonne par courbe. Séparateur « , » ou « ; » (export tableur français, virgule décimale acceptée). Données écrites dans la page (petits graphiques) : {% include graphique.html x_valeurs="0,1,2,3" y_valeurs="5,4.8,4.5,4.1" serie="Tension" x="Temps (h)" y="Tension (V)" %} Jusqu'à trois courbes : y_valeurs / serie, y_valeurs2 / serie2, y_valeurs3 / serie3. Valeurs séparées par « , » (décimales avec un point) ou par « ; » (décimales avec une virgule). Options : type="line" (défaut), "bar", "scatter" ou "radar" (x_valeurs = les branches) ; titre ; x et y (titres des axes) ; hauteur="300" (en pixels, sinon proportions 2:1 sur une page, hauteur fixe dans les slides). {%- endcomment -%} {%- assign _csv = include.csv -%} {%- assign _csv_url = nil -%} {%- if _csv -%} {%- assign _debut = _csv | slice: 0, 4 -%} {%- assign _premier = _csv | slice: 0 -%} {%- if _debut == 'http' -%} {%- assign _csv_url = _csv -%} {%- elsif _premier == '/' -%} {%- assign _csv_url = _csv | relative_url -%} {%- else -%} {%- assign _csv_url = page.url | append: _csv | relative_url -%} {%- endif -%} {%- endif -%}
