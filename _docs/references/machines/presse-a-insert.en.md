## Overview

A vertical press for installing heat-set threaded inserts (brass) into 3D-printed parts. A heating iron, mounted on a vertically guided linear rail, locally melts the plastic around the insert to set it in place, without having to do it freehand with a soldering iron.

## Technical specifications

| Parameter | Value |
|---|---|
| Iron power | 90 W |
| Temperature range | 180 to 500 °C, adjustable, digital display (°C/°F) |
| Linear rail travel | 210 mm |
| Tip length | 60 mm |
| Device height | 485 mm |
| Base | 163 x 140 x 30 mm |
| Compatible insert sizes | M2, M3, M4, M5, M6, M8 (tips supplied) |
| Compatible materials | PLA, PETG, ABS, ASA and other thermoplastic filaments |
