## Overview

A 2-in-1 post-processing station for resin 3D printing: a rotating tank washes the part in isopropanol (IPA) to remove residual uncured resin, then a UV LED chamber cures the part to harden it for good.

## Technical specifications

| Parameter | Value |
|---|---|
| Supply | 24V / 1.6A |
| UV radiation | Dual band, 385 nm and 405 nm |
| Wash tank | 4.5 L (190 x 154 x 200 mm) |
| Curing area | Parts up to Ø165 x 200 mm |
| Timer | Adjustable from 2 to 90 min |
| Speed | 3 adjustable speeds |
| Dimensions | 225 x 235 x 365 mm |
| Weight | 3.7 kg |
