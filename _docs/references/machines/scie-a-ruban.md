## Présentation

Scie à ruban portable pour la découpe de métal (barres, tubes, profilés). Une lame en boucle continue, entraînée en rotation, coupe la pièce fixée dans l'étau intégré. La base orientable permet des coupes d'onglet jusqu'à 45°.

## Caractéristiques techniques

| Paramètre | Valeur |
|---|---|
| Puissance | 1100 W |
| Alimentation | 220V / 50Hz |
| Vitesse de lame | 42 à 144 m/min, 6 niveaux réglables |
| Dimensions de la lame | 1140 x 13 x 0,65 mm |
| Capacité de coupe (sans base) | 127 x 127 mm |
| Capacité de coupe (avec base) | 99 x 81 mm |
| Rotation de la base | 0° à 45° |
| Poids | 13 kg |
