## Présentation

Station de post-traitement 2-en-1 pour l'impression 3D résine : un bac tournant lave la pièce à l'isopropanol (IPA) pour retirer la résine non polymérisée résiduelle, puis une chambre à LED UV polymérise la pièce pour la durcir définitivement.

## Caractéristiques techniques

| Paramètre | Valeur |
|---|---|
| Alimentation | 24V / 1,6A |
| Rayonnement UV | Double bande, 385 nm et 405 nm |
| Bac de lavage | 4,5 L (190 x 154 x 200 mm) |
| Zone de polymérisation | Pièces jusqu'à Ø165 x 200 mm |
| Minuterie | Réglable de 2 à 90 min |
| Vitesse | 3 vitesses réglables |
| Dimensions | 225 x 235 x 365 mm |
| Poids | 3,7 kg |

## Utilisation au MakerSpace

À compléter : règles d'accès, réservation. Voir les [consignes de sécurité du module Résine](/workshops/certification-securite/modules/resine/) avant toute utilisation : manipulation d'isopropanol (inflammable) et exposition aux UV.
