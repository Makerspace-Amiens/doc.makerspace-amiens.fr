## Overview

A portable band saw for cutting metal (bars, tubes, profiles). A continuous loop blade, driven in rotation, cuts the part clamped in the built-in vice. The swivelling base allows mitre cuts up to 45°.

## Technical specifications

| Parameter | Value |
|---|---|
| Power | 1100 W |
| Supply | 220V / 50Hz |
| Blade speed | 42 to 144 m/min, 6 adjustable levels |
| Blade dimensions | 1140 x 13 x 0.65 mm |
| Cutting capacity (without base) | 127 x 127 mm |
| Cutting capacity (with base) | 99 x 81 mm |
| Base rotation | 0° to 45° |
| Weight | 13 kg |
